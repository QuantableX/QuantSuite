## Default Permission

Default permissions for the QuantSystems module: settings, system configs, the evaluation engine and its cache.

#### This default permission set includes the following:

- `allow-get-app-settings`
- `allow-update-app-settings`
- `allow-list-systems`
- `allow-create-system`
- `allow-delete-system`
- `allow-get-system-config`
- `allow-save-system-config`
- `allow-start-engine`
- `allow-stop-engine`
- `allow-engine-status`
- `allow-live-eval`
- `allow-pair-markets`
- `allow-run-backtest`
- `allow-browse-universe`
- `allow-cache-stats`
- `allow-clear-cache`
- `allow-screenshot-to-clipboard`
