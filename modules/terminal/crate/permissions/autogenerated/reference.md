## Default Permission

Default permissions for the terminal module.

#### This default permission set includes the following:

- `allow-get-ohlcv`
- `allow-get-tickers`
- `allow-get-order-book`
- `allow-get-screener`
- `allow-get-correlation`
- `allow-get-marketcap`
- `allow-get-daily-change`
- `allow-get-sentiment`
- `allow-get-metric-history`
