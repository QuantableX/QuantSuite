## Default Permission

Default permissions for the pilot module.

#### This default permission set includes the following:

- `allow-pilot-status`
- `allow-pilot-contexts`
- `allow-pilot-settings-get`
- `allow-pilot-settings-set`
- `allow-pilot-sessions-list`
- `allow-pilot-session-create`
- `allow-pilot-session-open`
- `allow-pilot-session-launch`
- `allow-pilot-session-stop`
- `allow-pilot-session-delete`
- `allow-pilot-session-update`
- `allow-pilot-runtime-state`
- `allow-pilot-thread-create`
- `allow-pilot-thread-snapshot`
- `allow-pilot-thread-send`
- `allow-pilot-thread-answer`
- `allow-pilot-thread-interrupt`
- `allow-pilot-thread-update`
- `allow-pilot-provider-catalog`
- `allow-pilot-queue-list`
- `allow-pilot-queue-add`
- `allow-pilot-queue-update`
- `allow-pilot-queue-remove`
- `allow-pilot-queue-send-now`
- `allow-pilot-queue-resume`
- `allow-pilot-thread-steer`
- `allow-pilot-attachment-save-text`
- `allow-pilot-thread-arrange`
- `allow-pilot-files-search`
- `allow-pilot-attachment-save-image`
- `allow-pilot-attachment-save-file`
- `allow-pilot-skills`
- `allow-pilot-diff-list`
- `allow-pilot-diff-file`
- `allow-pilot-diff-action`
- `allow-pilot-thread-revert`
- `allow-pilot-git-info`
- `allow-pilot-git-branches`
- `allow-pilot-git-checkout`
- `allow-pilot-thread-set-workspace`
- `allow-pilot-worktree-previous`
