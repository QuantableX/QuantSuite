## Default Permission

Default permissions for the QuantMemory module: the markdown vault, its index, search, links and graph.

#### This default permission set includes the following:

- `allow-list-memories`
- `allow-get-memory`
- `allow-create-memory`
- `allow-update-memory`
- `allow-append-memory`
- `allow-rename-memory`
- `allow-set-memory-meta`
- `allow-delete-memory`
- `allow-restore-memory`
- `allow-list-trash`
- `allow-purge-trash`
- `allow-search-memories`
- `allow-get-backlinks`
- `allow-get-graph`
- `allow-get-orphans`
- `allow-get-unresolved-links`
- `allow-suggest-connections`
- `allow-get-stats`
- `allow-get-vault-info`
- `allow-set-vault-path`
- `allow-reindex-vault`
- `allow-list-tags`
- `allow-list-scopes`
- `allow-sync-base`
- `allow-list-base`
- `allow-get-base`
- `allow-describe-base`
- `allow-memory-context`
- `allow-get-embedding-config`
- `allow-set-embedding-config`
- `allow-index-embeddings`
- `allow-set-memory-quality`
- `allow-review-memory-quality`
- `allow-get-memory-review-queue`
