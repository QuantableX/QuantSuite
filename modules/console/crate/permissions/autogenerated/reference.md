## Default Permission

Default permissions for the console module.

#### This default permission set includes the following:

- `allow-open-session`
- `allow-write-session`
- `allow-resize-session`
- `allow-close-session`
- `allow-detach-session`
- `allow-attach-session`
- `allow-session-alive`
- `allow-list-sessions`
- `allow-list-shells`
- `allow-save-pasted-image`
