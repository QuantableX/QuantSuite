## Default Permission

Default permissions for the script module.

#### This default permission set includes the following:

- `allow-list-scripts`
- `allow-open-scripts-folder`
- `allow-read-script`
- `allow-check-script`
- `allow-save-script`
- `allow-list-versions`
- `allow-read-version`
- `allow-restore-version`
- `allow-create-script`
- `allow-delete-script`
- `allow-lint-script`
- `allow-script-python`
- `allow-store-sources`
- `allow-store-source-save`
- `allow-store-source-delete`
- `allow-store-token-set`
- `allow-store-token-clear`
- `allow-store-catalog`
- `allow-store-item`
- `allow-store-plan`
- `allow-store-install`
- `allow-store-remove`
