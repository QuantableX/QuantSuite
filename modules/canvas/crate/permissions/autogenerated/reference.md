## Default Permission

Default permissions for the canvas module.

#### This default permission set includes the following:

- `allow-read-dir-tree`
- `allow-read-file`
- `allow-write-file`
- `allow-create-file`
- `allow-delete-file`
- `allow-rename-file`
- `allow-search-files`
- `allow-read-file-binary`
- `allow-git-status`
- `allow-git-diff`
- `allow-git-stage`
- `allow-git-branch-list`
- `allow-git-log`
- `allow-git-commit-files`
- `allow-timeline-snapshot`
- `allow-timeline-list`
- `allow-timeline-read`
- `allow-workspace-storage-dir`
- `allow-load-canvas-state`
- `allow-save-canvas-state`
- `allow-browser-tab-open`
- `allow-browser-tab-place`
- `allow-browser-tab-close`
- `allow-browser-tab-navigate`
- `allow-browser-tab-action`
- `allow-browser-tab-capture`
- `allow-set-browser-clip-region`
- `allow-find-in-browser`
- `allow-load-browser-data`
- `allow-save-browser-data`
- `allow-design-list`
- `allow-design-read`
- `allow-design-write`
- `allow-design-comments`
- `allow-design-resolve`
- `allow-design-comment-add`
- `allow-design-comment-status`
- `allow-design-comment-delete`
- `allow-design-export`
- `allow-moodboard-list`
- `allow-moodboard-read`
- `allow-moodboard-create`
- `allow-moodboard-add`
- `allow-moodboard-caption`
- `allow-moodboard-reorder`
- `allow-moodboard-remove`
- `allow-moodboard-image`
